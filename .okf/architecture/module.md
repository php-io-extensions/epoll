# Scope

Linux `epoll(7)`, 1:1, plain C on the Zend API. Seven global functions, the `<sys/epoll.h>` constants, nothing else: no event loop, no wrapper object, no throwing on a failed call. Linux only: `config.m4` fails configure when `sys/epoll.h` is missing and `composer.json` lists `os-families: [linux]`.[^config][^composer]

Sibling extensions own the other kernel event APIs: ext-kqueue (macOS/BSD), ext-posi (POSIX calls). eventfd, timerfd and signalfd are not bound anywhere yet; when they are, they do not go in posi.

# Module globals

One field, `last_errno`, zeroed in GINIT (which also updates the TSRM cache under ZTS). No RINIT/RSHUTDOWN: nothing is allocated per request, so the errno simply carries across requests until the next failed call overwrites it.[^header][^epoll-c]

# Sockets dependency

`ZEND_MOD_OPTIONAL("sockets")` orders loading after ext/sockets when both are present. The `Socket` class is resolved by name from `CG(class_table)` at call time, never by linking against `php_sockets.so` symbols, so `epoll.so` loads with or without ext/sockets. The `#if __has_include("ext/sockets/php_sockets.h")` guard decides at compile time whether `Socket` objects are accepted at all; a build without the header rejects them with `TypeError`.[^epoll-c]

# Errno convention

Every function that wraps a syscall returns what C returns: an fd or `0` on success, `-1` on failure (`false` for the wait family, since they return arrays). On failure `errno` is saved into `last_errno` and read back with `epoll_errno()`. Nothing throws for a kernel error. The saved value is only written on failure, so a success does not clear a previous errno.[^epoll-c]

# Argument convention

PHP-side validation throws before the syscall; kernel-side validation returns `-1`:

| Check | Throws | Where |
|---|---|---|
| any `int` argument outside C `int` range | `ValueError` | `epoll_long_to_int()` |
| `$events` outside `uint32` (64-bit builds) | `ValueError` | `epoll_ctl` |
| `$fd` not `int`, stream resource, or `Socket` | `TypeError` | `epoll_zval_to_fd()` |
| closed stream / stream with no fd | `TypeError` / `ValueError` | `epoll_zval_to_fd()` |
| closed `Socket` | `ValueError` | `epoll_zval_to_fd()` |
| sigmask entry not `int` / not a valid signal number | `TypeError` / `ValueError` | `epoll_sigmask_to_sigset()` |
| `$maxevents` out of range | nothing: passed to the kernel through a one-slot buffer, kernel answers `EINVAL` | `epoll_events_buffer()` |

Streams are cast with `PHP_STREAM_AS_FD_FOR_SELECT | PHP_STREAM_CAST_INTERNAL`, so any stream that `stream_select()` would accept is accepted here.[^epoll-c]
